# 📚 Guia de Estudos — Linguagens de Programação e Fundamentos Básicos

Este repositório é um **guia de estudos pessoal sobre programação**, criado com o objetivo de organizar e compartilhar conhecimentos, anotações e referências que venho utilizando durante minha jornada como estudante de Engenharia de Software.

> ⚠️ **Importante:** não sou profissional ou especialista na área. Este material representa a minha experiência de estudo, algumas anotações e a forma como estou buscando compreender os conceitos de programação utilizando I.A para auxiliar no aprendizado sem copiar nada pronto.

A ideia de disponibilizar este conteúdo publicamente é simples: **aprender, organizar, revisar e compartilhar conhecimento**. Muitas vezes, algo que está sendo útil para os meus estudos também pode ajudar outra pessoa que esteja passando por uma etapa semelhante ou não tenha um método de estudos definido. Se esse guia puder te ajudar, já fico feliz!.

---

## 🎯 Objetivo

Este guia foi criado para me ajudar a construir uma base mais sólida em programação, principalmente nos conceitos fundamentais que podem ser aplicados em diferentes linguagens.
Hoje, meu conhecimento é bem básico e foco muito em aprender lógica de programação e algoritmos. Tentando entender a base por trás de cada instrução. Porém, ainda tenho dificuldades em transferir a lógica para a sintaxe da linguagem, e esses guias tem me auxiliado a não travar na parte de escrita de sintaxes.
Ainda faltam muitas linguagens para aprender e estudar, e pouco a pouco vou disponibilizando aqui conforme for praticando.
Mais do que decorar sintaxes, estou buscando entender:

* como os conceitos funcionam;
* por que determinadas abordagens são utilizadas;
* quais são as diferenças entre as linguagens;
* como transformar teoria em prática;
* como desenvolver uma base que facilite o aprendizado de novas tecnologias.

A programação possui muitas linguagens, frameworks e ferramentas, mas acredito que **uma boa compreensão dos fundamentos facilita bastante a evolução como desenvolvedor**.

---

## 🧠 Como estou utilizando este guia

Este repositório funciona como um **material de apoio aos meus estudos**.

A ideia é consultar os conteúdos, comparar diferentes formas de implementação, testar exemplos e, principalmente, colocar os conceitos em prática.

O conteúdo não deve ser encarado como uma sequência obrigatória ou como um curso completo. É um guia que está em constante evolução conforme novos conhecimentos são adquiridos.

📌 **Aprender programação é um processo contínuo.**

Por isso, este repositório pode receber alterações, correções, novos exemplos e novos assuntos ao longo do tempo.

---

## 💻 O que você pode encontrar aqui

O conteúdo está voltado principalmente para **fundamentos de programação e conceitos básicos das linguagens**, incluindo assuntos que ajudam na construção de uma base para continuar os estudos.

Entre eles, estão conceitos como:

* lógica de programação;
* variáveis e constantes;
* tipos de dados;
* operadores;
* estruturas condicionais;
* estruturas de repetição;
* funções;
* organização e estrutura de código;
* conceitos fundamentais das linguagens de programação;
* exemplos práticos;
* comparações entre diferentes formas de implementação.

A organização pode mudar com o tempo conforme o conteúdo for sendo aprimorado.

---

## 🔍 Por que estudar os fundamentos?

Durante o aprendizado de programação, é muito fácil ficar preso à sintaxe de uma determinada linguagem.

Por isso, este guia busca dar atenção também aos conceitos que aparecem de formas diferentes em diversas linguagens.

Entender os fundamentos pode ajudar a tornar o aprendizado de novas tecnologias mais natural, já que muitos conceitos continuam presentes mesmo quando a sintaxe muda.

> **A linguagem pode mudar. Os fundamentos continuam sendo importantes.**

## 🤝 Para quem este material pode ser útil?

Este guia pode ser interessante principalmente para quem:

* está começando a estudar programação;
* precisa revisar fundamentos;
* está estudando mais de uma linguagem;
* quer organizar melhor sua rotina de estudos;
* procura exemplos simples para entender determinados conceitos.

Ao mesmo tempo, este material deve ser encarado como **um guia de apoio**, e não como uma fonte definitiva sobre programação.
